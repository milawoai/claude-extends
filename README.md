# claude-extends

## 简介 / Introduction

**中文：**
这是一个用于存放自研的 Claude 代码扩展工具的仓库。旨在提供一系列提升开发效率的扩展工具和脚本。

**English:**
A repository for storing self-developed Claude code extension tools. This project aims to provide a series of extension tools and scripts to enhance development efficiency.

## 目录结构 / Directory Structure

```
claude-extends/
├── extensions/       # 扩展工具目录 / Extension tools directory
├── docs/            # 文档目录 / Documentation directory
├── examples/        # 示例代码 / Example code
└── README.md        # 项目说明 / Project description
```

## 使用方法 / Usage

1. 浏览 `extensions/` 目录查看可用的扩展工具
2. 参考 `docs/` 目录中的文档了解详细使用说明
3. 查看 `examples/` 目录获取使用示例

**English:**
1. Browse the `extensions/` directory to see available extension tools
2. Refer to documentation in the `docs/` directory for detailed usage instructions
3. Check the `examples/` directory for usage examples
