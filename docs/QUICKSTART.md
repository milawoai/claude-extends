# 快速开始 / Quick Start

## 中文

### 欢迎使用 claude-extends！

这个仓库是用于存放自研的 Claude 代码扩展工具的集合。

### 第一步：了解仓库结构

```
claude-extends/
├── extensions/       # 所有扩展工具都存放在这里
├── docs/            # 文档和指南
├── examples/        # 使用示例
└── README.md        # 项目说明
```

### 第二步：浏览模板示例

查看 `extensions/template-extension/` 目录，了解如何构建一个标准的扩展工具：

- 清晰的 README 说明
- 组织良好的源代码
- 双语注释和文档

### 第三步：添加你的扩展工具

1. 在 `extensions/` 目录下创建新文件夹
2. 按照模板结构组织你的代码
3. 编写详细的 README 文档
4. 提交 Pull Request

详细步骤请参考 [贡献指南](CONTRIBUTING.md)。

### 需要帮助？

- 查看 [贡献指南](CONTRIBUTING.md) 了解详细流程
- 参考 `template-extension` 示例
- 创建 Issue 提问

## English

### Welcome to claude-extends!

This repository is a collection of self-developed Claude code extension tools.

### Step 1: Understand the Repository Structure

```
claude-extends/
├── extensions/       # All extension tools are stored here
├── docs/            # Documentation and guides
├── examples/        # Usage examples
└── README.md        # Project description
```

### Step 2: Browse the Template Example

Check the `extensions/template-extension/` directory to learn how to build a standard extension tool:

- Clear README documentation
- Well-organized source code
- Bilingual comments and documentation

### Step 3: Add Your Extension Tool

1. Create a new folder in the `extensions/` directory
2. Organize your code following the template structure
3. Write detailed README documentation
4. Submit a Pull Request

For detailed steps, please refer to the [Contributing Guidelines](CONTRIBUTING.md).

### Need Help?

- Check the [Contributing Guidelines](CONTRIBUTING.md) for detailed procedures
- Reference the `template-extension` example
- Create an Issue to ask questions
